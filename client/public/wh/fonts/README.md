# Self-hosted fonts

Generated by `scripts/fetch-fonts.mjs`; the `@font-face` rules live in `src/wh/fonts.css`.

| family | use | licence |
|---|---|---|
| Inter (variable, opsz 14–32, wght 400–700, latin + latin-ext) | fallback text face behind the system UI font | SIL Open Font License 1.1 |

The product sets `-apple-system, "SF Pro Text", "Segoe UI"` first, so Apple and Windows users see their platform face; Inter carries everyone else with the same optical character. Icons are Lucide, rendered inline as SVG, so there is no icon font to subset.

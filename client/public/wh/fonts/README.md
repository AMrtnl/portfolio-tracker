# Self-hosted fonts

Generated by `scripts/fetch-fonts.mjs`; the `@font-face` rules live in `src/wh/fonts.css`.

| family | use | licence |
|---|---|---|
| DM Sans (variable, opsz 9–40, wght 400–700) | everything read or counted | SIL Open Font License 1.1 |
| Instrument Serif (regular, italic) | titles and the wordmark | SIL Open Font License 1.1 |
| Material Symbols Rounded (variable, subset) | icons, names listed in `src/wh/icons.ts` | Apache License 2.0 |

The icon font carries only the names in the icon map. Add a name there and re-run the script.

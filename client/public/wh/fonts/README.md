# Self-hosted fonts

Generated by `scripts/fetch-fonts.mjs`; the `@font-face` rules live in `src/wh/fonts.css`.

| family | use | licence |
|---|---|---|
| DM Sans (variable, opsz 9–40, wght 400–700, latin + latin-ext) | figures, labels, body text | SIL Open Font License 1.1 |
| Instrument Serif (regular and italic, latin + latin-ext) | titles, the wordmark, the line under the temple | SIL Open Font License 1.1 |

Figures are set in DM Sans with tabular numerals; titles in Instrument Serif. Icons are Lucide, rendered inline as SVG, so there is no icon font to subset.

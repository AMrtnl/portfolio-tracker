# Wealth Hub handoff

1. Copy this `wealth-hub-handoff/` folder into the root of the Wealth Hub repo.
2. Open the repo in Claude Code.
3. Paste the contents of `KICKOFF_PROMPT.md`.

Contents: `HANDOFF.md` (the spec), `tokens/` (CSS, JSON, Swift), `assets/` (8 logo SVGs, the dot-screen and mosaic images, the two source images), `reference/code/` (chart kit, chart styles, living mark, light map), `reference/screens/` (markup for 27 screens and guideline pages), `fixtures/demo-data.json` (one consistent dataset for every screen).
